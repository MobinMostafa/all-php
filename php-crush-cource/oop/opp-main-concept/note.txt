Part 1: Summary - All OOP Topics
OOP means Object Oriented Programming. You put data and the functions that work on that data together inside
one class. Almost every language (PHP, JavaScript, Java, C#, Python) uses the same ideas. Only the syntax is
different. This guide uses PHP for examples and shows exactly where Laravel uses each idea.
Total: 4 pillars + 16 topics. The 4 pillars are the big ideas. The 16 topics are the keywords and tools you write in
code. Every pillar is covered by the topics below.
The 4 Pillars of OOP
1. Encapsulation - hide data, allow change only through methods (topic 5).
2. Abstraction - show only what is needed, hide the details (topics 9, 10).
3. Inheritance - child class reuses parent class code (topic 8).
4. Polymorphism - same method name, different behavior (topic 12).

Quick answer: how many keywords?
PHP OOP keywords you must know: class, new, extends, implements, abstract, interface, trait, use, final, static, self, parent,
public, protected, private, readonly, const, enum, namespace, $this, instanceof, clone = 22 keywords. Magic methods: 7
important ones.
